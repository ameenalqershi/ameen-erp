2. **القرارات المانعة:** يجب تسجيل مرجع سياسة معتمدة أو ملف تحليل أصلي يحدد enum والـapproval/source contract. لا تُنشأ قيم أو مسارات محاسبية بالاستنتاج، ولا يُعطل الحارس `policy_unavailable` في SYS12/13 أو غيرهما.
3. **تسلسل الاستكمال بعد اعتماد المصادر:** SYS12/13 + أرصدة SAL/PUR ← GL02؛ PRJ/SAL/PUR + GL14/SYS09 ← GL03/GL05/GL07؛ SYS05/SAL11/PUR11 ← GL08؛ SYS03/GL04 ← GL09؛ مصادر المساعد/التقارير ← GL10 ثم GL11؛ عقد الموافقة/النافذة ← GL12.
