# GL06-GP03 — نص نطاق أرقام القيود

تُقبل معاملات GET `/journals/processing-queue` الحالية (`sequenceFrom` و`sequenceTo`) دون تغيير. أضيف اختيار `numberRange` نصي بديل ضمن نفس `periodId`، بصيغة رقم واحد (`JV-2026-000001`) أو نطاق (`JV-2026-000001..JV-2026-000007`). يمكن إدخال التسلسلات الرقمية مثل `1..7`، ولكن تُقيّد بالفترة والسنة المالية المطلوبة؛ لا تجمع الحقول الرقمية مع النصية.

التحقق من طول النص، وجود سنة مطابقة، أرقام موجبة، تسلسل تصاعدي، ورفض صيغ متعددة أو معطوبة يجري **بعد التحقق من التصريح**. لا يُغيّر هذا الاستعلام المستندات أو أرقامها ولا ينتج أثرًا ماليًا. تظل مرشحات الفرع والحالة والمصدر والصفحات مطبقة قبل عرض النتائج. أي قيد خارج الفرع المصرح مستبعد، وتظل بوابة فحص الترحيل وإعادة الاختبار قائمة.

الدليل: `JournalProcessingTests` و`JournalProcessingSqlIntegration` و`HostedApiIntegration` إضافة إلى نجاح بوابة CI. التغيير لا يعالج باقي فجوات GL06: مصدر المستندات الأخرى، سجل الفشل التقني الخارجي، إصدار مستقل للدفعة، ولا يساوي اكتمال الشاشة.
