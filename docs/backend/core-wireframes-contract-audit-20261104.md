# CORE WFR-01–06 — audit of backend contracts against six immutable wireframes

**Baseline:** main `8c767dea816c3d6ab3664b203f0b3cddbb496449`, original `muhaseb-erp-analysis/wireframes/*.svg`; 150 original screens and 2,759 fields. This is a backend **contract coverage audit**, not a UI design, Flutter implementation, or an assertion of full operational API readiness. The source models are **proposed mockups**, not observed screens of a reference application.

## Reproducible evidence

- `backend/scripts/tests/test_wireframe_contracts.py` parses the six original SVG files as XML. Each visible data label has an explicit numbered-field mapping to its own originating screen; visible labels without an approved backend field are tracked separately, never silently treated as implemented.
- The test requires exactly 2,759 unique field registry entries from `docs/backend/fields-implementation.csv`, checks all mappings against existing IDs and explicit statuses, and rejects missing labels, unapproved field IDs, wrong screen IDs or malformed SVG.
- Execute `python3 -m unittest discover -s backend/scripts/tests -p 'test_*.py'`; workflow `.github/workflows/backend.yml` already runs this and additional .NET SQL/JWT/OpenAPI verification through `backend/scripts/verify.py --sql`.
- The mapping checks **evidence integrity**; actual field readiness is taken from the current traceability registry and remains subject to live integration tests and module-specific acceptances.

## Acceptance boundary and follow-up

- These six tasks can be closed only as **read-only audits of the wireframe-to-backend contract** after successful final SHA CI and review; the underlying GL01/INV04/GL03/CASH03/SAL06/RPT01 implementation tasks remain accurately partial or not started.
- No original diagram, field dictionary, tax policy, financial rule, API, migration or other agent's domain code is changed.
- If a future implementation adds fields, rerun the audit and recheck the status matrix; the test deliberately does not hard-code a permanent `pending`/ `partial` state that would block valid progress.
