# GL03-A05 — معاينة أثر قيد اليومية قبل الترحيل

تطوير وظيفي جديد بتاريخ 2 نوفمبر 2026، وفق فعل «معاينة الأثر» في `muhaseb-erp-analysis/docs/modules/GL.md`، دون تغيير المصدر التحليلي.

## العقد

- `GET /api/v1/companies/{companyId}/journals/{id}/impact-preview` يتطلب JWT وعضوية قراءة للقيد ضمن الشركة والفرع.
- للقيود اليدوية أو مسودات العكس فقط؛ القيد المرتبط بمستند آلي يستعرض أثره من المصدر ولا يسمح لهذا المسار بالالتفاف على دورة المصدر.
- يعرض هوية القيد ورقم الإصدار/الرقم والتاريخ والحالة والعملة الوظيفية، مجموع المدين والدائن الوظيفيين والفارق، وعدد/تفاصيل السطور حسب ترتيبها، مع الحساب ومركز التكلفة وعملة السطر وسعره الأصلي والمرجع التاريخي و`FunctionalNet`.
- `CanSubmit` يعني أن القيد في حالة `Draft` وبلا مانع تحقق حالي، `ValidationErrorCode` يسجل سبب منع الاتزان/الفترة/الحساب كما في فحص التقديم نفسه؛ ليست المعاينة موافقة أو ترحيلًا ولا تمنح حجزًا للأرقام.
- قراءة فقط دون `Command` أو `AuditEvent` أو `OutboxEvent` أو تغير في الإصدارات/الأرصدة، ولا تعيد تسعير سطور أجنبية تاريخية.
- لا تدّعي المعاينة امتلاك سعر صرف صالح مستقبلاً أو فتح الفترة عند التنفيذ لاحقًا؛ يُعاد التحقق داخل أمر التقديم/الترحيل الفعلي.

## بوابة القبول

- `JournalImpactPreviewTests.cs`: معاينة قيد متزن دون كتابة، فرق قيد غير متزن بكود المنع الصريح، وعزل الفروع والمستخدم.
- `HttpIntegration.cs`: GET وعقد الأرقام العشرية والنطاق ورفض مستخدم غير مصرح.
- `HostedApiIntegration.cs`: GET من API نشر حقيقي عبر HTTPS/JWT/SQL معزول، دون أثر مالي.
- `OpenApiSnapshotTests.cs`: وجود GET مؤمن وعقد واضح، ثم البناء وفحص `traceability.py` و`progress.py`.
- تُقبل `GL03-A05` بعد نجاح CI للـSHA النهائي. لا يعني ذلك اكتمال شاشة GL03؛ المشروع والطرف وأنواع القيود والمرفقات والطباعة لا تزال متبقية.
