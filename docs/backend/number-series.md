# SYS10 — ترقيم المستندات القابل للإعداد

المرجع: SYS10-F01–F11 في التحليل الأصلي. API تحت `/api/v1/companies/{companyId}/number-series`: بحث وإنشاء وتفاصيل وPUT وتفعيل/تعطيل بسبب، وحجز مستقل، واستخدام وسجل تغييرات. يحفظ الشركة والفرع الاختياري والحالة ونوع المستند والسنة والبادئة الاختيارية والرقم التالي والمنشئ والوقت والإصدار العددي وآخر تعديل. كل تعديل يستخدم UUID مستقلًا لقفل التزامن ومفتاح إعادة طلب؛ لا تقبل الأوامر حقول التدقيق من العميل.

الأنواع التشغيلية الحالية Journal وInventoryOpening؛ TaxInvoice مرفوض حتى اكتمال TAX05 وملف الدولة، ولا يُختلق ترقيم ضريبي. مرجع السنة داخل الشركة وبه فترة مفتوحة، والفرع إن حُدد فعال ومصرح. السلسلة العامة تتطلب صلاحية جميع الفروع لإدارتها أو قراءة سجلها، والسلسلة الفرعية تقدم على العامة. تعطيلها يوقف التوليد ولا يسقط إلى سلسلة بديلة لتجاوز التعطيل.

تطبّق البادئة حرفيًا يليها الرقم بست خانات على الأقل؛ الفراغ يعني عدم وجود بادئة. الرمز `..` محجوز لنطاقات البحث. الرقم التالي لا يخفض، والأرقام القديمة والمحجوزة والملغاة لا يعاد استخدامها. تعارض سلسلتين في رقم مستند فعلي يرفض ذريًا ويستلزم بادئة أو رقمًا تاليًا مختلفًا، دون استهلاك خفي أو تكرار.

الحجز والعداد والتدقيق وإيصال الأمر والمستند في معاملة الشركة نفسها. تحفظ سجلات الحجز غير القابلة للتعديل رابط المستند ومفاتيحه الأجنبية المركبة؛ نقل المسودة لسنة أخرى يحفظ الحجز السابق ورابطه التاريخي. الحجز المستقل قد يبقى دون مستند ويظهر Reserved. جرى ربط القيد اليدوي والدوري والافتتاح وعكسه، وافتتاح المخزون، دون تغيير أرقام المستندات السابقة. يبقى الترقيم السابق للمصادر التي لم تضبط لها سلسلة.

عولجت اعتمادية GL06: النطاق النصي للأرقام المخصصة يحدد السلسلة والسنة والفروع ويمنع خلط العدادات؛ النطاق القديم يستبعد أرقام السلاسل المخصصة. لا تتغير العقود القديمة للمرشحات الرقمية.

SQL 023 بعد 022، ذرية وقابلة للإعادة، تنشئ إعدادات وسجلات فارغة دون تغيير التاريخ. يرفض دور التشغيل تعديل أو حذف الحجوزات؛ لا نشر أو ترقية إنتاجية تلقائية. تشمل الاختبارات البيانات والاختيارية والتزامن والتراجع والتعطيل والعزل والإلغاء ونقل السنة ومرجع المخزون وSQL وHTTPS/JWT وOpenAPI.
