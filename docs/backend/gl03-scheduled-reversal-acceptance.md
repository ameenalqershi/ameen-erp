# GL03-GP05 — تتبع تنفيذ العكس التلقائي المجدول

تقرير استكمال توثيق ومطابقة تنفيذ قائم بتاريخ 2 نوفمبر 2026، **وليس ادعاء تطوير ميزة جديدة** في هذه الدفعة. المصدر الأصلي غير المعدّل: `muhaseb-erp-analysis/docs/modules/GL.md`، حقلا `GL03-F14` و`GL03-F15` من `data/fields.csv`.

## العقد والحدود

- `CreateJournalRequest.AutomaticReversal` و`ReversalDate` مع تحرير اختياري وتفاصيل/قوائم `JournalEntry.AutomaticReversalDate` و`JournalSummary`، وأعمدة SQL ضمن الترقية `026_scheduled_journal_reversals.sql`.
- `POST /api/v1/companies/{companyId}/journals/reversals/run-due` يختار القيود اليدوية المرحّلة التي حل موعدها وينشئ **مسودة عكس فقط**؛ لا اعتماد ولا ترحيل آلي، ولا تعديل للأثر المالي السابق.
- يتطلب العضوية وصلاحيتي `Reverse` و`Draft` مع تقاطع الفروع المرخصة. يستخدم مفتاح إعادة ثابتًا لكل قيد وفحص سجل العكس التاريخي حتى بعد الإلغاء لمنع إعادة التوليد. يفصل نجاح/فشل كل قيد وفق سياسة العمل القائمة.
- عامل `ReversalDraftScheduler` **اختياري وغير مفعّل تلقائيًا**؛ يحتاج إعداد `ReversalScheduler:Enabled` وهوية `ActorSubject` بعضوية حقيقية ومخولة. لا يوجد إثبات بأن العامل مفعّل في VPS/الإنتاج.
- لا يعني إغلاق هذه الفجوة اكتمال GL03 أو GL07؛ ما زالت أنواع القيود `GL14` والمرفقات والمشروع والطرف واعتماديات أخرى غير مكتملة.
