# GL02-A05 — معاينة أثر الافتتاح العام

تحقيق فعل «معاينة الأثر» من المصدر الأصلي `muhaseb-erp-analysis/docs/modules/GL.md` دون تعديل التحليل.

- `GET /api/v1/companies/{companyId}/general-openings/{id}/impact-preview` يفرض وجود مصدر `GeneralOpening`، والتحقق من عضوية قراءة الشركة ونطاق الفرع قبل إظهار تفاصيل حسابات القيد.
- يستخدم فحص الاتزان والفترة والحسابات نفسه في دورة التقديم الفعلية؛ يعرض المدين والدائن الوظيفيين والفارق وسطور العملات/أسعارها التاريخية، لكن دون حجز مستند أو تغيير Audit/Outbox/الأثر المالي. يظهر `CanSubmit` للمرحلة Draft مع فحص ناجح فقط.
- لا يسمح بمصدر القيد اليدوي في مسار الافتتاح، ولا يُفترض أن هذه المعاينة تُصفّر الرقابات أو تُجري تسويات دفاتر العملاء والموردين التي لم تُنفذ.
- اختبارات `GeneralOpeningTests.cs` للاتزان وعدم الكتابة والعزل ورفض النوع الخاطئ؛ `HostedApiIntegration.cs` عبر SQL/HTTPS/JWT؛ `OpenApiSnapshotTests.cs` لتوثيق المسار والتفويض.
- تتطلب بوابة الاعتماد نجاح البناء والاختبارات وCI مع SQL معزول وربط المصفوفات. لا يعني ذلك اكتمال GL02 أو تنفيذ GL02-C01/GP04/GP05 أو الطباعة والاستيراد.
