## بوابات الدول السبع

| الدولة | ما يلزم قبل التفعيل |
|---|---|
| اليمن | تحديد موقع المنشأة والجهة المختصة والنشاط والتسجيل والنصوص السارية؛ لا تعمم منطقة أو تسجيلًا على أخرى |
| السعودية | تحديد موجة الإلزام والمواصفة السارية وSDK/بيئة الاختبار والشهادة ومسار الاعتماد أو الإبلاغ وإجراءات الانقطاع |
| الإمارات | التحقق من مرحلة التطبيق الحالية ومواصفات تبادل الفاتورة ومزود القناة وتسجيل المنشأة |
| عمان | تحديد المرحلة التي تشمل المكلف ومواصفات الفوترة السارية |
| البحرين | مراجعة النص المحدث ومتطلبات النشاط والتسجيل وتصحيح الفاتورة |
| قطر | التحقق من تاريخ النفاذ والتسجيل والوضع القانوني الحالي؛ لا تُنسخ VAT من دولة أخرى |
| الكويت | المرجع الأصلي لا يثبت الوضع الحالي بمرجع رسمي كافٍ؛ تبقى القواعد الضريبية غير مفعلة حتى التحقق |

1. لا توجد جهة/مالك قرار معيّن في سجل V1 لاعتماد ملف الدولة أو تفسير الاختلافات القانونية؛ سُجل ذلك UNASSIGNED بدل اختلاق مالك.

3. مراحل الفوترة الإلكترونية، إصدار الهوية، الشهادات، SDK، مزود الإرسال، التعامل مع الرفض والانقطاع وإعادة المحاولة تحتاج مواصفة رسمية معتمدة.
4. الربط مع SAL06/PUR07/POS06 وTAX snapshots والدفاتر وOUTBOX غير موجود على main.
5. متطلبات اللغة والتقويم والطباعة والاحتفاظ والرواتب والتأمينات وتكلفة الاستيراد ما زالت مرتبطة بمهام وحدات غير مكتملة.
6. لا يجوز تحويل نسبة 10% أو أي مثال حسابي في التحليل إلى قيمة افتراضية للإنتاج.
