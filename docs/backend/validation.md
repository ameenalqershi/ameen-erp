## ما بقي خارج هذا التحقق

- ربط جهة هوية المستخدمين الفعلية وإعداد التسجيل وMFA وسياسات جلسات النشر. الجهة المؤقتة تثبت مسار OIDC/JWT، ولا تختبر إعداد جهة إنتاج بعينها.
- تشغيل GitHub Actions عن بعد وبناء Docker؛ الملفات جاهزة، ولا يوجد مستودع بعيد موصول في هذه الجلسة.
- SQL Server 2022 لم يُختبر محليًا؛ CI معدّ لتشغيله. البيئة المحلية المستخدمة هي SQL Server 2025.
- أداء الأرشيف الكبير والحمل والنسخ والاستعادة والتعافي وإعداد المراقبة والشهادات وحدود الطلبات للنشر.
- الوظائف والحقول غير المنفذة في مصفوفة المطابقة؛ لا توجد واجهة أمامية ضمن هذه الدفعة.

التقارير الحالية تحسب التجميع في التطبيق بعد قراءة البيانات ذات الصلة؛ لا يوجد اختبار حمل أو ضمان snapshot بين استعلامات متعددة متزامنة مع تغييرات الإعداد. نجاح الاختبارات الحالية لا يحل هذين القيدين.

## إعادة التحقق

استخدم SDK 10 وفق `backend/global.json` وعرّف `AMEEN_TEST_SQL_CONNECTION` لاتصال **خادم اختبار** يسمح بإنشاء قاعدة مؤقتة. الحزمة تحذف القاعدة ذات الاسم العشوائي التي أنشأتها فقط.

```bash
python3 backend/scripts/verify.py --sql
```

يدعم الأمر `--dotnet /path/to/dotnet` عند وجود SDK خارج PATH. دون `--sql`، تُشغل اختبارات النواة وخريطة SQL ومضيف HTTP الاختباري، وتظهر اختبارات SQL والمضيف الفعلي متجاوزة صراحة. تحفظ الأدلة تحت `backend/.artifacts/`، والعقد المولد القابل للمراجعة في [openapi/v1.json](../../backend/openapi/v1.json).

أضافت دفعة SYS04/COST01 عدد 24 سيناريو في المشغل، وفحوص SQL للتزامن وفشل التدقيق والتراجع ومراجع الأب والمسؤول بين الشركات، وطلبات HTTPS لإنشاء البطاقات وتحريرها والبحث عنها وقراءة استعمالها وتدقيقها. نوع المركز ما زال معلقًا، ولم تُختبر وحدة موازنات أو توزيعات غير منفذة.

أضافت دفعة SYS01 اثني عشر سيناريو لملف الشركة وتعديل العملة قبل الاستخدام والتقويم والتعطيل والصلاحيات والتراجع. نجحت أيضًا فحوص SQL لتزامن تعديل البطاقة وفشل التدقيق والتراجع واستكمال بطاقة قديمة، وترقية 005→006 الذرية القابلة للإعادة، وطلبات HTTPS فعلية للتعديل والتعطيل وإعادة التفعيل مع JWT.

أضافت دفعة SYS02 اثني عشر سيناريو للشجرة والعنوان ونطاق الصلاحيات والمركز الافتراضي والتعطيل وأثره على الترحيل والتوليد الدوري. نجحت فحوص SQL للتعديل المتزامن وإعادة الطلب، ومنع دورة ناتجة عن نقلين متزامنين، والتراجع عند فشل التدقيق، ودور التشغيل، ومفاتيح الشركات المركبة، واستكمال العنوان القديم. اختبرت ترقية 006→007 مع فشل DDL ثم إعادة التطبيق، ومسارات SYS02 عبر HTTPS وJWT. بقي مرجع المدير ونوع الموقع غير منفذين.
