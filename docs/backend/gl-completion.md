# خطة إغلاق الأستاذ العام — القسم النشط

توجيه المستخدم: التركيز على إكمال قسم واحد قبل الانتقال لغيره، إلا للضرورة. القسم المختار GL (14 شاشة). تظل هذه الأولوية سارية في الجلسات التالية. لا تساوي نسبة ربط الحقول اكتمال القسم، ولا تعلن إغلاق شاشة حتى تحقق حقولها وأفعالها وضوابطها ودليلها.

| المرحلة داخل GL | العمل | الحالة/المانع |
|---|---|---|
| GL05/GL06 | قائمة مراجعة ومعاينة ومعالجة مستقلة لكل قيد وسجل نتائج | دفعة منفذة؛ بقيت مراحل الاعتماد ورأس الإجراء وتوجيه المصادر والسجل التقني الدائم |
| GL02 | الافتتاح العام وتسوية الرقابات ومنع ازدواج التفصيل | بدأت دورة المصدر والاعتماد والترحيل والعكس واستبعاد الرقابات ومعاينة التسوية؛ التالي بوابة المطابقة/القطع واستكمال فجوات العقد. استخدم INV06 الموجود دون فتح ميزات مخزون جديدة. SAL03/PUR03 غير منفذتين، فلا تدع مطابقة شاملة لهما |
| GL14 ثم GL03 | أنواع القيود وربطها باليومية، تعديل بيانات المسودة والعكس المجدول والمرفقات | اكتمل تعديل رأس المسودة والسطور في GL03 وGL02 مع ضبط الفترة والفرع والترقيم والسعر؛ قيم القوائم وسياسات الربط غير المفصلة توثق ولا تختلق مطابقة نهائية؛ الطرف والمشروع اعتماديتان خارجيتان |
| GL04/GL07/GL09 | استكمال التكرار والعكس المجدول والمقدمات والمستحقات | مصدر قيد واضح واعتماد وترحيل وإعادة آمنة لكل استحقاق |
| GL08 | تقييم أرصدة العملات | لقطة أسعار وتاريخ أثر وقيد فروق وعكس مرتبط، دون إعادة كتابة التاريخ |
| GL10 | مطابقة الحسابات الرقابية | البدء بالدفاتر المنفذة فقط؛ الذمم والبنوك والضريبة والأصول اعتماديات لا يمكن إعلان مطابقتها قبل تنفيذها |
| GL11/GL12 | إقفال السنة وإعادة الفتح المؤقت وموافقاته | إقفال GL لا يعني إقفال ERP مع غياب الدفاتر المساعدة |
| GL13/GL01 | ربط القوائم والتدفقات، مراجعة حماية الدليل واستخدامه | ربط واضح يمنع ازدواج تصنيف الحساب واختبارات اتزان |
| تدقيق الإغلاق | مراجعة جميع حقول وأفعال وقواعد GL01–GL14 والتشغيل | توثيق كل فجوة باقية قبل إعلان اكتمال القسم |

عند ظهور اعتمادية خارج GL: سجل الشاشة المانعة والوظيفة الدنيا اللازمة لها؛ أكمل المستقل داخل GL أولًا. لا تتحول تلقائيًا إلى قسم مخزون أو تقارير أو تهيئة كامل. لا توجد شاشة GL مغلقة بالكامل حاليًا وفق بوابة المطابقة، ووجود endpoints ليس دليل إغلاق.
