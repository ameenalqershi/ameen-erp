# الفروع والإدارات SYS02

تنفذ هذه الدفعة شجرة الفروع، والعنوان، والاسم الإنجليزي والملاحظات، ومركز التكلفة الافتراضي، والتعديل والتعطيل والبحث والاستخدام والتدقيق. تبقى الشاشة جزئية: لا يحدد التحليل قيم «نوع الموقع» ولا مرجع «المدير»؛ طُلب توضيحهما، ولم يفترض التنفيذ قائمة أو ربطًا بالعضويات بدل الموظفين.

## العقد والمسارات

جميع المسارات تحت `/api/v1/companies/{companyId}/branches` وتتطلب الهوية. الكتابة تتطلب `Idempotency-Key` وصلاحية `company.configure` لكل الفروع؛ التعديل والحالة يتطلبان `expectedVersion` وسببًا.

| المسار | العملية |
|---|---|
| GET / POST | القائمة ضمن نطاق المستخدم / إنشاء |
| GET /search | بحث بالرمز أو الاسمين؛ parentId وisActive وoffset وlimit |
| GET /{id} | بطاقة فرع ضمن نطاق المستخدم |
| PUT /{id} | استبدال بيانات البطاقة |
| POST /{id}/status | تفعيل أو تعطيل مع سبب وإصدار |
| GET /{id}/usage | أعداد الأبناء والمراكز والعضويات والقيود والقوالب، وفحص استخدام الفرع وأبنائه؛ قراءة لكل الفروع |
| GET /{id}/audit-events | أحداث بطاقة الفرع مع الصفحات؛ قراءة وتدقيق لكل الفروع |

إنشاء الفرع أصبح يتطلب المدينة والعنوان؛ يجب تحديث العملاء السابقين:

```json
{
  "code": "MAIN",
  "name": "الفرع الرئيسي",
  "city": "صنعاء",
  "address": "عنوان الفرع الفعلي",
  "parentId": null,
  "defaultCostCenterId": null,
  "englishName": "Main branch",
  "notes": null
}
```

التعديل يستقبل الحقول نفسها مع expectedVersion وreason، وكل حقول طلب التعديل مطلوبة في JSON حتى عند null. المدينة حتى 200 حرف والعنوان حتى 500؛ الاسم الإنجليزي حتى 200 والملاحظات حتى 2000. النص الفارغ مرفوض. Revision عدد صحيح يبدأ من 1 ويزيد عند التعديل وتغيير الحالة، وVersion رمز التزامن التقني. إعادة الطلب المطابق لا تزيد الإصدار أو تكرر التدقيق.

## الضوابط

الأب ضمن الشركة نفسها وفعال، ولا يسمح بدورة مباشرة أو غير مباشرة. تغيير الرمز أو الأب محجوب إذا استخدم الفرع أو أحد أبنائه في قيد بأي حالة أو قالب دوري، حتى إن كان ملغى أو معطلًا. تبقى البيانات الوصفية قابلة للتعديل تحت التدقيق. هذه حماية محافظة للتجميع التاريخي؛ لا تنفذ عملية إعادة هيكلة تاريخية.

الشجرة تنظيمية؛ صلاحيات العضويات تبقى قائمة معرفات صريحة. صلاحية الأب لا تمنح صلاحية الأبناء، ومرشح أب محجوب يرفض. التقارير الحالية تعمل بمعرف الفرع المختار، ولا تجمع الشجرة تلقائيًا.

تعطيل الأب يتطلب تعطيل أبنائه الفعالين أولًا، وتفعيل الابن يتطلب سلسلة آباء فعالة وعنوانًا مكتملًا. تعطيل الفرع يمنع العمليات التي تتحقق من الفرع الفعال، ومنها إنشاء القيد والتحقق منه وتقديمه واعتماده وترحيله وتوليد القيد الدوري. يظل التاريخ والتقارير متاحين وفق الصلاحيات. لا يلغي التعطيل تلقائيًا العضويات والمراكز والقوالب ولا يغير القيود المرحّلة. إعادة الطلب السابق تبقى محكومة بقواعد المصادقة وإعادة الطلب القائمة؛ لا يمثل تعطيل الفرع إلغاءً لتاريخ الأوامر.

المركز الافتراضي يجب أن يكون فعالًا وعامًا أو تابعًا للفرع نفسه. عند إنشاء فرع جديد يمكن اختيار مركز عام، ثم إنشاء مركز خاص بالفرع وتعيينه بالتعديل. يمنع تعطيل مركز مرتبط كافتراضي، أو نقله إلى فرع لا يشمل البطاقات المرتبطة به، حتى لو كانت هذه الفروع معطلة. أزل الربط أولًا. المركز الافتراضي إعداد محفوظ؛ لا يملأ سطور القيود آليًا ولا يتجاوز شرط مركز الحساب، ولا يبدل المراكز التاريخية.

ملخص الاستخدام يحسب أيضًا العضويات المعطلة والعضويات ذات صلاحية كل الفروع، والقيود الملغاة والقوالب المعطلة. ليست الأعداد تفويضًا للحذف، ولا توجد عملية حذف للفرع. البحث والاستخدام غير مثبتين باختبار حمل واسع أو لقطة متزامنة مضمونة.

## ترقية 007

طبّق [007_branch_cards.sql](../../backend/database/007_branch_cards.sql) بعد 001–006 ثم runtime-role.sql. الجاهزية تتطلب الإصدار 7، ولا يطبق API الترقية آليًا. تحفظ الترقية الرمز والمعرف والحالة وVersion، وتبدأ Revision من 1، وتترك العنوان والمدينة والأب والمركز الافتراضي والحقول الاختيارية null للبطاقات السابقة. لا تختلق عنوانًا من بطاقة الشركة.

الفروع القديمة تبقى قابلة للقراءة، لكن العمليات التي تتطلب فرعًا فعالًا ترفض البطاقة الناقصة برمز `branch_profile_incomplete`. استكمل المدينة والعنوان عبر PUT قبل استئناف التشغيل. `isProfileComplete` يفحص هذين الحقلين فقط، ولا يعني اكتمال المدير ونوع الموقع المعلقين.

اختبارات [BranchTests.cs](../../backend/tests/Ameen.Erp.Tests/BranchTests.cs) تشمل الشجرة والنطاق والقيد والمركز الافتراضي والتراجع. يختبر [BranchSqlIntegration.cs](../../backend/tests/Ameen.Erp.Tests/BranchSqlIntegration.cs) التزامن ودور التشغيل والمفاتيح المركبة؛ وتغطي حزمة التحقق ترقية DDL الفاشلة وإعادتها والطلبات الفعلية عبر HTTPS وJWT.
