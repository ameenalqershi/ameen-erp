# التقارير ومراحل التنفيذ المقترحة

## عقد التقرير

كل تقرير يحمل الشركة والفروع والفترة والعملة ونمط التحويل والحالة ووقت الاستخراج، ويتيح الرجوع إلى المصدر وفق الصلاحية. التصدير يطابق المرشحات الظاهرة. الإجمالي التجميعي يحسب من السطور الأصلية مرة واحدة لا من إجماليات متداخلة.

| التقرير | الأعمدة الجوهرية | معيار المطابقة |
|---|---|---|
| ميزان المراجعة | حساب، اسم، رصيد أول مدين/دائن، حركة مدين/دائن، رصيد آخر | اتزان العملة الوظيفية ومعادلة الرصيد |
| الأستاذ | تاريخ، نوع ورقم المصدر، بيان، مدين، دائن، رصيد، مركز، عملة | مجموع حركة الحساب في الميزان |
| كشف العميل/المورد | فاتورة، استحقاق، قيمة، دفعات، إشعارات، رصيد | مجموع البنود المفتوحة = الرقابة بعد فصل المقدم |
| أعمار الذمم | غير مستحق، 1–30، 31–60، 61–90، أكثر من 90 أو شرائح معرفة | الرصيد التاريخي بعد التسويات حتى تاريخ التقرير |
| اليومية | القيد، مصدره، حالة اعتماده، حسابات، مبالغ، منشئ ومعتمد | مجموع المدين = الدائن لكل قيد |
| المركز المالي | أصول، التزامات، حقوق، أرقام مقارنة | المعادلة المحاسبية وربط كل حساب بالبند |
| الدخل | صافي إيراد، تكلفة، مجمل ربح، مصاريف، نتيجة | مطابق للأستاذ دون ضريبة المخرجات |
| التدفقات النقدية | تشغيلي، استثماري، تمويلي، أثر صرف، افتتاح وختام | تسوية النقد مع المركز المالي |
| حركة وتقييم المخزون | صنف، مخزن، وحدة أساسية، أول، داخل، خارج، ختام، تكلفة، قيمة | ربط الحركة والقيمة بحساب الرقابة |
| الصلاحية والراكد | دفعة، تاريخ انتهاء، أيام حتى الانتهاء، آخر حركة، كمية وقيمة | استبعاد الخدمة؛ توضيح العزل والطريق |
| المبيعات والربحية | عميل/مندوب/صنف، إجمالي، خصم، مرتجع، صافي، تكلفة، هامش | هامش = (الصافي − التكلفة) ÷ الصافي؛ الصافي صفر يعرض غير معرف |
| المشتريات | مورد، صنف، طلب، استلام، مفوتر، مردود، تكلفة شحن | مصدر تكلفة واحد ومطابقة الثلاثة |
| النقدية والشيكات | صندوق/بنك، قبض، صرف، رصيد؛ شيك وحالة واستحقاق | الأرصدة حسب الحالة لا القيمة الاسمية لكل الشيكات |
| الأصول | افتتاح تكلفة ومجمع، إضافات، إهلاك، استبعاد، ختام وصافي | الرقابتان: الأصل ومجمعه |
| الموازنة | بند ومركز، مخطط، فعلي، التزامات، انحراف، نسبة | نسخة خطة محددة ومنع جمع الالتزام الذي تحول لفاتورة |
| الرواتب | موظف، أساسي، بدلات، استقطاعات، سلف، صافي، حالة سداد | مجموع الصافي = استحقاق الرواتب قبل السداد |
| المشروعات | عقد، تغيير، إنجاز، مستخلص، محصل، محتجز، تكلفة، نتيجة | التمييز بين المطالبة والإيراد والمقبوض |
| الضرائب | وثيقة، فئة، وعاء، نسبة، قيمة، استرداد، إشعار مرجعي | ربط الإقرار بالسجل وبالأستاذ |
| الاستثناءات | خصم زائد، تجاوز ائتمان، سعر صرف معدل، فترة مفتوحة، فشل إرسال | كل حدث له مستخدم وسبب وموافقة |

يمكن الوصول إلى تقارير المجال من داخل القسم أو مركز التقارير دون إنشاء محرك حساب مختلف لكل مدخل.

## مراحل تنفيذ لاحقة

1. **تثبيت المطابقة:** إصدار المرجع، شجرة القوائم، عينات الشاشات، ومراجعة محاسب؛ النتيجة مصفوفة فروق معتمدة.
2. **الأساس:** الشركات والفترات والصلاحيات والعملة والدليل ومحرك الترحيل والتدقيق؛ بوابة قبول AT01–03 وAT25.
3. **التجارة:** المخزون والشراء والبيع والذمم والنقدية؛ بوابة AT04–15 وAT21 وAT26–28.
4. **التوطين:** ملف دولة واحدة أولًا، الضرائب والطباعة والفوترة واختبارات بيئة الجهة؛ بوابة AT18 وAT27 ومتطلبات الدولة.
5. **التوسع:** الأصول ونقاط البيع والاستيراد والموازنات؛ بوابة AT13 وAT16–17.
6. **الامتدادات:** الرواتب ثم التصنيع ثم المشروعات وفق أولوية المستخدم؛ بوابة AT22–24.
7. **التجربة والتحويل:** نقل بيانات تجريبي، مطابقة، استعادة، تشغيل موازٍ وقرار بدء.

لا يحدد هذا التحليل تقنية أو موعدًا أو تكلفة تنفيذ قبل معرفة الفريق والحجم والتكاملات. المطلوب الحالي هو تحليل وتصميم؛ هذه المراحل مرجع للخطوة التالية التي سيحددها المستخدم.
