# نطاق التحليل وقرارات التصميم

الإصدار 1.0 — تاريخ البحث 2026-10-20 — المرحلة: تحليل قبل البرمجة.

الغرض: تأسيس نظام محاسبي عربي مألوف لمحاسبي المنشآت التجارية والخدمية في اليمن والخليج، مع امتدادات للتصنيع والمشروعات والموارد البشرية. الاسم «محاسب» اسم عمل مؤقت للمجلد، لا اسم تجاري معتمد.

**درجة الاكتمال:** هذه حزمة تحليل مرجعية شاملة للنطاق المحدد أدناه، وليست شهادة بمطابقة جميع شاشات إصدار بعينه من المتكامل. تفاصيل الحقول والتصاميم والضوابط المقترحة عمل تحليلي مستقل. المصادر العامة تثبت الوظائف الرئيسية، لكنها لا تكفي لإثبات تطابق ترتيب كل حقل أو اختصار أو تقرير.

## المرجع الوظيفي وحدود المطابقة

افتراض العمل أن المقصود منتجات يمن سوفت. توجد مسميات المتكامل برو، الفضي، وبلاس الذهبي؛ لا تُدمج خصائصها في ادعاء عن إصدار واحد. الصفحات الرسمية تؤكد وجود الحسابات والمخزون والمبيعات والمشتريات والعملات والصلاحيات. [المتكامل برو](https://yemensoft.com/ar-motakamel-pro-system/) و[المتكامل بلاس](https://yemensoft.com/ar-motakamel-plus-erp-solutions/).

الأسماء الشائعة مثل دليل الحسابات وسند القبض وفاتورة المبيعات مستخدمة لتقليل عبء التعلم. الترتيب البصري والألوان والمفاتيح المقترحة ليست منسوبة إلى واجهة المنتج المرجعي.

تُستكمل المطابقة الحرفية عند تحديد الإصدار والبناء والوحدات المفعلة، ثم مقارنة دليل رسمي كامل أو جلسة استعراض مرخصة. تعذر فتح ملفات أدلة الإصدار 5 الموجودة في نتائج البحث؛ لم تُعامل محتوياتها على أنها مقروءة أو مؤكدة.

## مستويات النطاق

| المستوى | الأقسام | المقصود |
|---|---|---|
| الأساس المحاسبي والتجاري | التهيئة، الحسابات، النقدية والبنوك، المخزون، المبيعات والعملاء، المشتريات والموردون، التقارير، توطين الضرائب | تصميم تفصيلي للشاشات والحقول والقيود والدورات |
| التوسع التشغيلي | نقاط البيع، الاستيراد والاعتمادات، الأصول، الموازنات والتكاليف | تصميم وظيفي قابل للتفعيل حسب حجم المنشأة |
| الامتدادات | الموارد البشرية والرواتب، التصنيع، المشروعات والمقاولات | تحليل حدود التكامل والشاشات والمدخلات؛ السياسات القطاعية تحتاج اعتمادًا قبل التنفيذ |
| خارج هذه النسخة | تشغيل المستشفيات، المطاعم، الفنادق، المدارس، الذهب، إدارة شركات الصرافة المرخصة | لا يُفترض أنها تصبح مكتملة بمجرد وجود حسابات ومخزون |

وجود العملات المتعددة والصناديق لا يعني بناء نظام شركات صرافة أو حوالات مالية عام. نظام الاستيراد يدير مشتريات المنشأة واعتماداتها.

## الافتراضات العملية

1. الواجهة عربية من اليمين لليسار، مع أسماء إنجليزية اختيارية وطباعة ثنائية اللغة.
2. يمكن إدارة شركات قانونية مستقلة وفروع ومخازن. لكل شركة عملتها الوظيفية ودفترها وفتراتها؛ لا يُسمح بقيود مختلطة بين شركتين.
3. مخزون مستمر، ومتوسط مرجح متحرك أو FIFO وفق سياسة مثبتة قبل الحركة. تغيير الطريقة بعد التشغيل مشروع تحويل مستقل.
4. الحسابات الرقابية للعملاء والموردين والمخزون تُغذى من الدفاتر المساعدة. لا يرحل المستخدم إليها بقيد عام دون مسار تسوية مضبوط.
5. الحفظ مسودة؛ الاعتماد يثبت الموافقة؛ الترحيل ينشئ الأثر المحاسبي. يمكن دمج أزرار العمل حسب الصلاحية مع بقاء الأحداث منفصلة.
6. لكل مستند مصدر واحد للأثر. الفاتورة التي تستدعي إذنًا سابقًا لا تكرر كمياته أو تكلفته.
7. اليمن والسعودية نقطتا البدء المفترضتان. الإمارات وعمان والبحرين وقطر والكويت ملفات توطين منفصلة، لا سياسة خليجية موحدة.
8. التشغيل عبر شبكة داخلية أو خادم مركزي قرار لاحق. انقطاع الإنترنت لا يسمح بتجاوز شروط إصدار الفاتورة المحلية.
9. لا توجد بيانات حقيقية أو أسرار أو حسابات مستخدمين في الأمثلة.

## معيار قبول التحليل

لكل شاشة: معرف ثابت، قسم ومسار قائمة، مستخدم مستهدف، هدف، حقول typed مع الإلزام ومصدر القيمة، أفعال، تحقق، مخرجات وأثر، ارتباطات واختبار قبول. لكل قسم: خريطة شاشة وملف شرح. الدورات الحساسة لها مخططات مستقلة. المطابقة مع المنتج المرجعي لها سجل فجوات صريح.
