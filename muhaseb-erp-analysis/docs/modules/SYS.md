# إدارة النظام والتهيئة

النطاق: أساسي. المستخدم الرئيسي: مدير النظام.

التهيئة الآمنة للشركات والمستخدمين والفترات.

خريطة الشاشات: [SVG](../../diagrams/svg/module-SYS.svg) | [Mermaid](../../diagrams/source/module-SYS.mmd).

كل التفاصيل التالية تصميم مقترح مستقل؛ التطابق التفصيلي مع إصدار المتكامل لم يُثبت. الحقول الموروثة موسعة لتيسير التنفيذ لاحقًا.
