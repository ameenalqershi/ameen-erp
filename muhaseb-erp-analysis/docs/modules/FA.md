# الأصول الثابتة

النطاق: توسع. المستخدم الرئيسي: محاسب الأصول.

إثبات الأصول وإهلاكها ونقلها واستبعادها.

خريطة الشاشات: [SVG](../../diagrams/svg/module-FA.svg) | [Mermaid](../../diagrams/source/module-FA.mmd).

كل التفاصيل التالية تصميم مقترح مستقل؛ التطابق التفصيلي مع إصدار المتكامل لم يُثبت. الحقول الموروثة موسعة لتيسير التنفيذ لاحقًا.
