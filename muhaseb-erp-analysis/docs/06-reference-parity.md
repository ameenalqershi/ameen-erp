## نموذج المقارنة لكل شاشة

`parity-matrix.csv` يحتوي صفًا لكل شاشة: معرفنا، اسمنا، اسم المرجع، إصدار المرجع، مرجع الصفحة/اللقطة، حالة الدليل، فرق الحقول، فرق السلوك، قرار المعالجة، المسؤول، وتاريخ التحقق.

الحالات المسموحة: غير متحقق، موثق جزئيًا، مطابق وظيفيًا، اختلاف مقصود، مطابق تفصيليًا. لا تتحول الحالة إلى «مطابق تفصيليًا» إلا مع دليل يغطي الحقول والسلوك والاختصارات والتقارير المعنية.

## طريقة المقارنة المقترحة

1. تثبيت نسخة المرجع والإعدادات على شركة تدريب.
2. جرد شاشات كل قسم وربطها بمعرفات هذا التحليل.
3. تسجيل الحقول والمصدر والإلزام والحالات ورسائل المنع؛ استبعاد البيانات الحقيقية.
4. تنفيذ شراء ثم بيع ثم مرتجع ثم تحصيل متعدد العملات، ومقارنة الأثر والتقارير.
5. تسجيل الفروق واعتمادها مع محاسب يستخدم النظام المرجعي.

استكمال هذه المقارنة لاحقًا هو الطريق لإثبات طلب «لا يجد المحاسب فرقًا». الحزمة الحالية لا تقدم نسبة مطابقة مخمنة.
